# Исследование в личном чате MAX

Личный чат использует три навыка из каталога `skills/`. Исследование имеет приоритет в вопросах о фактах. Для текста на основе предоставленных материалов бот сверяет факты в них, а для приветствия и работы над формулировками сохраняет обычный диалог. Результат поиска содержит источники, даты при наличии и отдельно отмеченные пробелы. При исчерпании времени или числа вызовов бот возвращает уже найденные источники.

Ранее переданные технические материалы сверяются с официальной документацией и проверками проекта. Их статус и ссылки хранятся в отдельном справочнике. Владелец добавляет другие материалы через `/material Название | текст`. Личный диалог получает только релевантные разделы справочника и явно добавленные материалы. Входящие сообщения, файлы, история проектов и общая память из этого пути недоступны. Содержание источников передаётся модели как данные.

Проверки: воспроизвести исчерпание поиска из MAX, сравнить свежие результаты с датами, проверить три роли и использование сохранённого материала, прогнать полный тестовый набор на сервере и обновить службу Maxframe после прохождения тестов.
