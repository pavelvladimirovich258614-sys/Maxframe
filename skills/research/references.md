# Проверенные технические материалы Maxframe

## MAX Bot API, события, токен и сертификат

Основа: переданный пакет документации MAX и отчёт повторного аудита миграции. Подтверждено на 10.11.2026: рабочий клиент обращается к `platform-api2.max.ru`, авторизация идёт через заголовок Authorization, запрос GET /me выполнен с реального сервера. Для этого подключения служба доверяет российскому корневому сертификату. Справочник: https://dev.max.ru/docs-api/methods/GET/me

Уточнение: MAX рекомендует webhook для постоянной эксплуатации. В Maxframe сейчас используется проверенный long polling, пока у пульта нет публичного адреса. Факт ответа в polling не доказывает, что webhook настроен. Форматы событий и способы получения: https://dev.max.ru/docs-api/use-cases/event-notifications

## MiniMax, Claude и инструменты диалога

Основа: первоначальная документация описывала Claude. Для текущего проекта это устарело: исполнитель Maxframe использует MiniMax через совместимый API. Сохранение reasoning_content в истории вызовов инструментов подтверждается документацией MiniMax и тестами. Личный чат получает разрешённые инструменты погоды и поиска при наличии конфигурации. Подключение к приложению MiniMax Desktop и дискам владельца из этого не следует. Источник: https://platform.minimax.io/docs/api-reference/text-openai-api

## SearXNG, DDGS и DuckDuckGo

Основа: переданное сравнение поиска DuckDuckGo и SearXNG, документация DDGS. Подтверждено: SearXNG предоставляет JSON-поиск, категорию news и фильтр периода. В тесте сервера вернул новости и обычные результаты. Результаты включают ссылки и выдержки, дата доступна не для каждой публикации. Документация: https://docs.searxng.org/dev/search_api.html

DDGS — отдельная Python-библиотека метапоиска с выбором движков. В её документации указан Yandex среди движков текстового поиска. В текущем Maxframe DDGS не развёрнут, его выдача с сервера не сравнивалась. Источник: https://github.com/deedy5/ddgs

## Яндекс Погода, Ангарск и прогноз

Основа: предоставленный кабинет API для умного дома и запрос о погоде в Ангарске. Подтверждено на 10.11.2026: сервер получает текущую погоду и почасовой прогноз через Яндекс Погоду. Координаты города подбираются через Open-Meteo. Наблюдения из прежнего ответа быстро устаревают, их нельзя переносить в ответ о текущей погоде. Источники: https://yandex.ru/pogoda/b2b/smarthome и https://open-meteo.com/en/docs/geocoding-api
